# Stability Index

From the official Node.js documentation:

- **Stability: 0 - Deprecated**  
  The feature may emit warnings. Backward compatibility is not guaranteed. Avoid in new code. Migration path is usually documented.

- **Stability: 1 - Experimental**  
  The feature is not subject to Semantic Versioning rules. Non-backward compatible changes or removal may occur in any future release. Use only for exploration or with feature flags when required. May emit a warning.

- **Stability: 2 - Stable**  
  Compatibility with the npm ecosystem is a high priority. The API is unlikely to change in breaking ways.

When answering questions, surface the stability of the API if it is 0 or 1. Prefer Stable APIs whenever possible.
