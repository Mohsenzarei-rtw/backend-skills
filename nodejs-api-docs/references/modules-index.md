# Node.js Core Modules Index (LTS focused)

Primary documentation base: https://nodejs.org/docs/latest-v24.x/api/

Replace `24` with `22` or `26` as needed.

| Module | File | Short description |
|--------|------|-------------------|
| Assertion testing | assert | Strict and loose assertions for tests |
| Asynchronous context tracking | async_context | AsyncLocalStorage and related |
| Async hooks | async_hooks | Low-level async resource tracking (mostly superseded) |
| Buffer | buffer | Binary data handling |
| C++ addons | addons | Writing native addons |
| C/C++ addons with Node-API | n-api | Stable ABI for native addons |
| C++ embedder API | embedding | Embedding Node.js in C++ applications |
| Child processes | child_process | spawn, exec, fork |
| Cluster | cluster | Multi-process scaling |
| Command-line options | cli | node CLI flags |
| Console | console | console.log and friends |
| Crypto | crypto | Hashing, encryption, certificates, Web Crypto |
| Debugger | debugger | Built-in debugger |
| Deprecated APIs | deprecations | List of deprecated APIs |
| Diagnostics Channel | diagnostics_channel | Diagnostic channels |
| DNS | dns | DNS resolution |
| Domain | domain | Deprecated error handling domains |
| Environment Variables | environment_variables | process.env related |
| Errors | errors | Error codes and handling |
| Events | events | EventEmitter |
| File system | fs | File I/O (sync, callback, promises) |
| Globals | globals | Global objects (Buffer, process, etc.) |
| HTTP | http | HTTP server and client |
| HTTP/2 | http2 | HTTP/2 support |
| HTTPS | https | HTTPS server and client |
| Inspector | inspector | V8 inspector integration |
| Internationalization | intl | ICU / Intl support |
| Iterable Streams API | stream_iter | Async iteration helpers for streams |
| Modules: CommonJS | modules | require / module.exports |
| Modules: ECMAScript modules | esm | import / export, loaders |
| Modules: node:module API | module | module.createRequire, register, etc. |
| Modules: Packages | packages | package.json, exports, imports, dual packages |
| Modules: TypeScript | typescript | TypeScript support (type stripping etc.) |
| Net | net | TCP / IPC sockets |
| OS | os | Operating system info |
| Path | path | Path manipulation |
| Performance hooks | perf_hooks | Performance measurement |
| Process | process | process object, signals, stdio |
| Punycode | punycode | Deprecated punycode |
| Query strings | querystring | querystring.parse / stringify |
| Readline | readline | Interactive line-by-line input |
| REPL | repl | Read-Eval-Print-Loop |
| Report | report | Diagnostic reports |
| Single executable applications | single-executable-applications | SEA |
| SQLite | sqlite | Built-in SQLite (experimental in some versions) |
| Stream | stream | Readable, Writable, Transform, pipeline |
| String decoder | string_decoder | Decoding buffers to strings |
| Test runner | test | Built-in test runner (`node:test`) |
| Timers | timers | setTimeout, setInterval, setImmediate |
| TLS/SSL | tls | TLS sockets |
| Trace events | tracing | Trace events |
| TTY | tty | Terminal control |
| UDP/datagram | dgram | UDP sockets |
| URL | url | URL parsing and resolution |
| Utilities | util | util.promisify, inspect, types, etc. |
| V8 | v8 | V8 specific APIs |
| VM | vm | Script execution in contexts |
| WASI | wasi | WebAssembly System Interface |
| Web Crypto API | webcrypto | Web Cryptography API |
| Web Streams API | webstreams | WHATWG Streams |
| Worker threads | worker_threads | Worker threads |
| Zlib | zlib | Compression |
